⚠️ Condiciones Claras del Programa

1. Cuándo se paga el 5%: Tu comisión se transfiere únicamente cuando el cliente reciba su pedido en la casa y cancele la totalidad de la compra (efectivo o transferencia). Si no compra o devuelve el producto, no se genera pago.

2. Precios vigentes y actualización de tarifas: Al referido se le aplicará el precio oficial vigente al momento exacto de su compra. Los precios pueden variar frente a compras anteriores según costos de fábrica y materias primas. No aplican rebajas adicionales para garantizar el pago oportuno del 5%.

3. Solo para Clientes Nuevos: Aplica únicamente para personas que nunca antes hayan comprado con nosotros. El registro en este formulario se debe realizar antes de que el cliente visite o contacte al almacén.

4. Guardar el Pantallazo (Comprobante): Al enviar este formulario se generará un pase en pantalla. Tómale una captura de pantalla y consérvala; es el soporte para saber a quién transferirle el dinero una vez entregado el pedido.

5. Tiempo de Vigencia (90 Días / 3 Meses): El cliente cuenta con 90 días calendario a partir de este registro para concretar su compra.

6. Productos Participantes: Aplica únicamente para colchón ortopédico resortado, semi ortopédico resortado, clínico y combos completos (base + cabecero + colchón). NO aplica para ventas de bases solas, cabeceros solos ni colchonetas.

7. Transporte y Envíos: El envío es GRATIS dentro de Verbenal. Para entregas fuera de Verbenal, el almacén apoya con $20.000 pesos de subsidio al transporte, y el cliente cancela el excedente directamente al transportador de confianza al recibir en su casa.
